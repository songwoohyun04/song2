# 스마트 GIF 생성기 (CineMotion Film Lab)

**국립한국해양대학교(KMOU)** 공식 CI 로고가 적용된 감성적이고 낭만적인 시네마틱 동영상 GIF 제작 스튜디오입니다.

---

## 🌟 최신 업데이트 및 주요 기능

### 1. 글자 꼴(폰트) 다양화 & 마우스 자유 드래그 배치
- **5가지 감성 글꼴 지원**:
  - `모던 산세리프` (Pretendard 기반의 깔끔한 고딕)
  - `감성 나눔명조` (문학적이고 클래식한 세리프)
  - `낭만 손글씨` (감성적인 필기체 감성)
  - `임팩트 밈` (유튜브 썸네일 & 볼드 밈 자막)
  - `레트로 타자기` (빈티지 모노스페이스)
- **마우스 & 터치 자유 드래그**:
  - 뷰파인더 화면 위의 **스티커**와 **자막**을 마우스로 직접 잡고 원하는 위치 어디든 자유롭게 끌어다 놓을 수 있습니다.
  - 드래그된 상대 좌표 비율이 GIF 렌더링 시 캔버스에 정확히 반영됩니다.

### 2. 실제 자연 & 동물 실사 샘플 비디오 원클릭 체험
- 그래픽 그림이 아닌, 실제 촬영된 고화질 실사 동영상을 로컬에 구비하여 1초 만에 불러와서 체험할 수 있습니다:
  - **🌊 [에메랄드 바다 파도]**: 아름답게 부서지는 실제 푸른 바다 물결과 파도 실사 영상 (`samples/ocean_waves_real.mp4`)
  - **🦁 [야생의 사자]**: 드넓은 초원 위에서 살아 숨쉬는 위풍당당한 사자 동물 실사 영상 (`samples/lion_wildlife.mp4`)
  - **🌿 [자연 숲속 토끼와 나비]**: 초록빛 풀밭과 꽃잎 사이로 뛰노는 귀여운 토끼와 나비 실사 영상 (`samples/nature_forest_animal.mp4`)

### 3. 내가 만든 GIF 갤러리 & 기록 관리 (IndexedDB)
- 지금까지 생성한 모든 GIF 애니메이션이 브라우저 로컬 데이터베이스(`IndexedDB`)에 영구 저장됩니다.
- 새로고침하거나 브라우저를 껐다 켜도 내가 만든 GIF 기록을 언제든 감상하고 **다시 다운로드**할 수 있습니다.
- 원치 않는 항목을 **개별 삭제**하거나, 상단의 **[전체 기록 삭제]** 버튼으로 손쉽게 정리할 수 있습니다.

### 4. 100% 무중단 초고속 Octree GIF 인코더 엔진
- 안전 타임아웃 방어막(Safety Seek Guard)이 장착되어 어떠한 환경이나 동영상에서도 멈추지 않고 매끄럽게 프레임을 캡처합니다.
- 선명한 256색 Octree 양자화기로 30~50프레임 분량의 고품질 GIF도 2~3초 만에 완성됩니다.
- 변환 완료 시 우측 다운로드 버튼이 활성화되며 확장자를 제외한 **`원래파일명.gif`**로 자동 저장됩니다.

## 🚀 실행 방법

### 방법 1. 원클릭 실행 (추천)
- 폴더 내 **`run.bat`** 파일을 더블 클릭하면 브라우저가 바로 열립니다.

### 방법 2. 웹 브라우저에서 바로 열기
- 폴더 내 **`index.html`** 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 바로 사용합니다.

### 방법 3. 파이썬 로컬 서버로 실행
```bash
python app.py
```
- 포트 8080에서 로컬 웹 서버가 열리며 기본 브라우저가 자동 실행됩니다.
